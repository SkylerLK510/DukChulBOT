Start with two persistent workers behind the existing send interface, each owning one gateway connection. Each tenant contributes 30 requests per minute; a request occupies one worker for 10 milliseconds. Two workers therefore complete 200 requests per second and can accept 200 × 55 = 11,000 requests within the deadline. That accommodates at most floor(11,000 / 30) = 366 tenants. At 367 tenants, 11,010 requests take 55.05 seconds. Treat 366 as a ceiling, not an operating target.
